# Byte Play — сайт (загрузка по FTP)

Все файлы в этой папке — статические. Загрузите **содержимое** папки в корень сайта
(обычно `public_html/`, `www/` или `httpdocs/`), сохраняя имена файлов.

## Файлы

| Файл | Что это |
|---|---|
| `send.php` | Обработчик формы заявки: сохраняет заявку на сервере и отправляет письмо |
| `index.html` | Главная страница (RU/EN, переключатель языка, форма заявки). Сборка от 01.10.2026 (редизайн v2) |
| `Privacy_Policy.html` | Политика конфиденциальности — актуальная, от 27.08.2026 |
| `Privacy_Policy_prev.html` | Политика конфиденциальности — предыдущая редакция |
| `Privacy_Policy_EN.html` | Privacy Policy — current, August 27, 2026 |
| `Privacy_Policy_EN_prev.html` | Privacy Policy — previous version |
| `Eula.html` | Пользовательское соглашение (RU) |
| `Eula_EN.html` | End User License Agreement (EN) |

## Важно

- Загружайте файлы **в бинарном режиме** (в FileZilla — Transfer → Transfer type → Binary),
  иначе может «поехать» кодировка.
- Все ссылки внутри относительные, поэтому сайт работает и в корне домена,
  и в подпапке (например `byteplay.fun/legal/`).
- Нужен хостинг с PHP 7.4+ (есть на любом обычном хостинге). Node и база данных не нужны.
- Форма заявки работает через `send.php` на вашем сервере — сторонние сервисы не используются.
  Каждая заявка:
  1. сохраняется в CSV-файл `byteplay-leads/leads-ГГГГ-ММ.csv` уровнем выше корня сайта
     (если туда нельзя писать — в `leads/` внутри сайта, закрытую от доступа из браузера);
  2. отправляется письмом на `admin@byteplay.fun` (Reply-To — email клиента).
- Адреса меняются в начале `send.php` (`$TO`, `$FROM`). `$FROM` должен быть ящиком на вашем
  домене, иначе письма могут попадать в спам.
- Если хостинг на nginx без .htaccess — убедитесь, что заявки пишутся в `byteplay-leads/`
  вне корня сайта, либо закройте папку `leads/` в панели хостинга.
- `index.html` — собранный файл со встроенными шрифтами и изображениями.
  Шрифты (Unbounded, Manrope) хранятся внутри файла — обращений к Google Fonts
  и другим внешним сервисам при загрузке страницы нет.
  Не редактируйте его вручную: правки вносятся в исходник и файл пересобирается.

## Проверка после загрузки

Откройте `https://ваш-домен/` — должна открыться главная. Затем проверьте ссылки
в футере: «Политика конфиденциальности» и «Пользовательское соглашение».
